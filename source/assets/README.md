# riverside_forest — asset pipeline

All 3D assets are generated by Blender (5.1.2, headless) Python scripts — no downloaded assets.

| step | tool |
|---|---|
| model + export JSON bundle | `blender/*.py` via `~/.cache/motion-video-deps/blender/bin/blender -b --python <script>` (helpers: `blender/bl_common.py`) |
| far-LOD impostors + normal cleanup (flora) | `make_lod2.py` (needs numpy: `uv run --with numpy python3 assets/make_lod2.py flowers_meadow plants_water_edge`) |
| mid-LOD (decimate) | `blender/lodify.py -- <bundle> 0.3 _lod1 260` |
| quantize + gzip + inline into the HTML, inject JS modules | `build_assets.py` (`uv run --with numpy python3 assets/build_assets.py <bundles...>`) |

Bundles in `out/`: animals (deer…dragonfly), house_shell, house_int_living|kitchen|bedroom (replace the old house_interior), flower_box, flowers_meadow, plants_water_edge (+ `.meta.json`).
house_shell, house_interior, flower_box, flowers_meadow, plants_water_edge (+ `.meta.json` with pivots/habitat/colliders/lights).

Runtime modules (concatenated into the HTML before the post-processing section): `assetlib.js` (decoder), `fauna.js` (AI + animation),
`flora.js` (instanced meadow/water plants with 3 LODs and triangle budgets), `cabin.js` (house shell + interior, doors (E), lights, colliders).

Verification: headless chromium (playwright-core) with SwiftShader; wait for new frames (`renderer.info.render.frame`) before screenshots.

## Village (added later)
`village_core.js` (site, terrain plane flattening, layout, road stamps) and `village.js` (buildings from `village_houses`, props from `village_props`,
villagers `villager_*` with rigid-part walk/work/sit animation + daily routine + E-to-talk dialogue, livestock `animal_*`, chimney smoke, night window glow).
Models: `blender/vh_*.py` (houses), `vl_*.py` (villagers), `vp_*.py` (props/livestock). Rebuild everything: `uv run --with numpy python3 assets/build_assets.py` (no args = all bundles except house_interior).
